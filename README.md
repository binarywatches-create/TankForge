# TankForge

Android arcade tank game prototype (Kotlin + Canvas).

GitHub Actions builds a debug APK on every push to main. Download it from Actions → Android APK build → Artifacts → TankForge-debug-apk.

Current build: single-player arcade tank game with touch movement, firing, four enemy classes, destructible brick walls, score, lives, terrain bonuses, progressive stages and a boss encounter every fifth stage. Wi-Fi/LAN transport and Bluetooth are not yet integrated into gameplay.
